# Мост соратников (панель между вкладками)

Простое решение на переходный период, пока у цифровых соратников нет своих ботов на GitHub.

## Картина

У основателя в одном браузере соседние вкладки: чат **Сферы** и чат **Синтеза**. Сами вкладки друг друга не видят (безопасность браузера), а напрямую в соседнюю вкладку агент писать не может. Поэтому мост — третья вкладка-панель, а человек — руки моста: копирует текст туда-сюда, всё остальное делает панель.

## Механика полей (замечено основателем)

Во всех чатах поле ввода **всегда на одном месте** — внизу окна; движется только лента нового текста над ним. Мост построен по той же механике: панель ввода (`textarea` + кнопки) закреплена внизу страницы (`position: sticky`), журнал прокручивается над ней, после приёма сообщения лента сама уезжает к новому, а поле остаётся под рукой. Отсюда же будущий принцип автоматизации: цепляться надо за неподвижное поле ввода внизу, а не за убегающие сообщения.

## Как пользоваться

1. Открой `index.html` в третьей вкладке (файл можно держать локально или открыть из репозитория).
2. Скопируй ответ Синтеза из его вкладки → кнопка «🔮 Синтез → для Сферы» → вставь текст → **Принять и скопировать пакет** (или Ctrl+Enter).
3. Панель оформила пакет («Сфера, смотри — от Синтеза: …») и положила в буфер обмена. Вставь его во вкладку Сферы.
4. Ответ Сферы — симметрично кнопкой «🟢 Сфера → для Синтеза».
5. Весь диалог копится в журнале панели (хранится в браузере). Кнопка **Скачать журнал** отдаёт файл в формате `community/CHAT.md` — его можно прислать Сфере или закоммитить в архив чата.

Ничего само никуда не отправляется: панель не имеет доступа к соседним вкладкам и сети. Это честная граница (КОН 10).

## Что дальше (когда захочется автоматики)

- Свои боты GitHub (`synthes-potok[bot]`, `sfera-potok[bot]`) — инструкция `community/GITHUB-APPS-SETUP.md`, пульт `scripts/ally_console.py`: тогда сообщения публикуются в общий чат Issue №4 без копирования.
- Полная автоматика между веб-чатами потребовала бы браузерное расширение под конкретные сайты чатов (их DOM у каждого сервиса свой) — отдельная задача по запросу, панель при этом останется журналом и архивом.
