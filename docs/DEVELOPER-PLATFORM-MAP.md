# Платформа разработчиков GitHub: что можно подключить в ПОТОК

Обзор по официальной документации GitHub (раздел Apps/API, Models, Codespaces, Actions, Packages, Pages). «Отдел для разработчиков» в настройках (Settings → Developer settings) — это только вход; вокруг него несколько отделов платформы, каждый что-то добавляет проекту. Отмечено: ✔ уже у нас, ◐ частично, ✚ может добавить новое.

## Отдел разработчика: три вида ключей и программ

| Инструмент | Суть по документации | У нас |
|---|---|---|
| **GitHub Apps** | Рекомендуемый путь: точечные права, короткоживущие токены (1 час), действует сам как бот `[bot]` или от имени пользователя, выбираются конкретные репозитории при установке, встроенные вебхуки, не привязан к человеку и не занимает место | ✔ `sfera-potok`, `synthes-potok`; это наш главный вид программ |
| **OAuth Apps** | Старый путь: действует только от имени пользователя, широкие скоупы вместо точечных прав, токены не истекают до отзыва. Документация прямо советует вместо них GitHub Apps | ✖ не нужны: всё, что OAuth умеет «от имени основателя», честнее делать Apps+PAT Русла |
| **Personal access tokens** (classic/fine-grained) | Ключи человека для скриптов; fine-grained — точечно по репозиториям и правам (напр., `models`) | ✔ PAT владельца у Русла; Сфере значения не передаются |

Вывод отдела: программная форма проекта — **Apps**, уже выбрана верно. OAuth Apps нового не дадут.

## Отделы платформы вокруг: что добавляет каждый

| Отдел/возможность | Что добавляет проекту | Статус и цена входа |
|---|---|---|
| **REST/GraphQL API** | Всё, чем соратники действуют в доме (задачи, обсуждения чтением, метки, релизы) | ✔ используется; Discussions-запись приложению Arena закрыта платформой |
| **Webhooks у Apps** | События дома приходят сами (без опроса): новый комментарий в чате → бот реагирует | ◐ мосты сейчас опросные; приёмник на машине Русла поднимет живой отклик |
| **GitHub Models** ✚ | Каталог моделей с OpenAI-совместимым эндпоинтом `models.github.ai/inference` по PAT со скоупом `models` | **Новое**: ChatDev на ноутбуке основателя получает моделей разных семей (OpenAI/Meta/xAI и др.) по одному ключу GitHub — без отдельных ключей провайдеров; лимиты — для прототипирования |
| **Actions + Marketplace** | Автоматика репозитория: наш CI уже здесь; рядом — CodeQL (поиск уязвимостей), Dependabot (обновления зависимостей), релизные экшены | ✔ CI свой + добавлен `.github/workflows/codeql.yml` (Go, push/PR/еженедельно) и `.github/dependabot.yml` (gomod, github-actions) |
| **Security** (Dependabot alerts, secret scanning) | Иммунитет шире тестов: алерты по зависимостям и утёкшим секретам | ◐ конфиги в репозитории; алерты в настройках включает основатель |
| **Packages (GHCR)** ✚ | Публикация Docker-образа организма из CI | **Новое**: `docker run` одной командой для любого соратника; у нас Dockerfile уже есть |
| **Codespaces + devcontainer** ✚ | Среда разработки в браузере по `.devcontainer/devcontainer.json` (Go, инструменты) | ✔ **Подключено Сферой**: `.devcontainer/devcontainer.json` (Go 1.22, gh, порт дашборда 8080, сборка при создании). Человек-соратник открывает проект и запускает без локальной установки |
| **Pages** | Сайт-витрина из папки docs | ◐ не включено; публичному репозиторию доступно, включается основателем |
| **Copilot отделы** (Spaces, custom agents `.github/agents`, skills) | Контекст и агенты для пользователей Copilot | Изучено (`docs/COPILOT-SPACES-MAP.md`); потребитель — Copilot, не круг |
| **MCP (официальный сервер GitHub)** | Инструменты GitHub для MCP-клиентов соратников | Карта готова (`community/MCP-GITHUB.md`), ждёт клиента у людей |
| **CLI `gh` и расширения** | Терминальные руки (Русло уже вооружён) | ✔ |

## Полнота проекта: что ещё есть на платформе (сверено 2026-11-18)

| Возможность | Что добавляет | Состояние/чья рука |
|---|---|---|
| **Releases + теги** | Версии организма как артефакты: бинарники Go под платформы, заметки релиза | ◐ релизов ещё не было; автоматика (сборка бинарников в Actions при теге) — Сфера/Синтез, первый тег — с живым запуском |
| **Аттестации сборки** (build provenance) | Подписанное происхождение артефактов релиза | ✚ вместе с релизами, одним экшеном |
| **SECURITY.md + private vulnerability reporting** | Канал приватных сообщений о уязвимостях | ✔ `SECURITY.md` создан Сферой; тумблер отчётности включает основатель (Settings → Security) |
| **Правила веток (rulesets, required checks, CODEOWNERS-review)** | `main` нельзя сломать случайно: обязательный зелёный CI и ревью | ◐ CODEOWNERS есть; правила на ветку ставит основатель (на публичном доступно) |
| **Топики и соц. превью репозитория** | Находимость и лицо витрины | ✖ ставит основатель в Settings (About) |
| **Профиль человека `COL-O/COL-O`** | Лицо основателя рядом с домом | ✖ личный репозиторий основателя — его рука |
| **Sub-issues и типы задач** | Иерархия задач внутри Issues | ◐ sub-issues доступны; типы задач — в организации |
| **Sponsors (FUNDING.yml)** | Кнопка поддержки проекта | ✖ только если круг решит принимать поддержку; платёжные данные — основатель |
| **Marketplace-публикация приложения** | `sfera-potok` как публичное приложение для других | ✖ рано: приложение дома, не продукт |

## Что подключить первым (по пользе для круга)

1. **GitHub Models → ChatDev**: основатель создаёт fine-grained PAT со скоупом моделей (значение — только на его ноутбуке, как все ключи), ChatDev-узлы получают `BASE_URL=https://models.github.ai/inference`. Это закрывает вопрос «разные модели по API» без новых провайдеров.
2. **`.devcontainer` с Go**: один файл в репозиторий — и проект открывается/запускается из браузера; полезно будущим соратникам и как запасная машина.
3. **CodeQL + Dependabot в CI**: иммунитет по безопасности рядом с тестами, бесплатно на публичном.
4. **GHCR-образ организма по тегам**: организм становится раздаваемым артефактом, а не только исходником.
5. **Pages-витрина манифеста** — когда круг захочет сайт (слово основателя).

Граница прежняя (КОН 10): ни один отдел платформы не расширяет токен сессии Arena и не отменяет ботов; отделы добавляют возможности **дому и людям**, а соратники действуют своими каналами.
