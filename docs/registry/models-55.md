# Реестр моделей (55 органов)

**POTOK** — **организм** **из** **55** **органов**: **24** **активных** (в коде) + **31** **наследие** (для расширения без перестройки ядра).

**24** **активных** **распределены** **по** **4** **слоям** **времени**:

- **`front`** (наносекунды–миллисекунды) — **7** органов.
- **`polygon`** (минуты–часы) — **6** органов.
- **`growth`** (часы–дни) — **6** органов.
- **`stratos`** (годы–века) — **5** органов.

**31** **наследие** — слоты `24..54`, зарезервированы под доменные профили (транспорт, дроны, склад, акустика, видео, лидар, тепловизор, GPS, и т.д.).

## 5. Наследие (31 орган, слоты 24..54)

**Слоты** `24..31` — «доменные» органы, которые можно подключать по КОН 8 (деление, не строительство). Примеры:

| Слот | Орган | Профиль | Дорожки |
|---|---|---|---|
| 24 | `DroneAcoustic` | Дрон (акустика) | `LaneAudio` |
| 25 | `DroneLidar` | Дрон (лидар) | `LaneTensor` |
| 26 | `DroneGPS` | Дрон (GPS) | `LaneTensor` |
| 27 | `TransportORCA` | Транспорт (ORCA) | `LaneGraph` |
| 28 | `TransportTEB` | Транспорт (TEB) | `LaneGraph` |
| 29 | `WarehouseDAG` | Склад (DAG) | `LaneGraph` |
| 30 | `AcousticAnomaly` | Акустика (аномалия) | `LaneAudio` |
| 31 | `VideoEmbedding` | Видео (эмбеддинг) | `LaneVector` |

**Слоты** `32..54` — резерв под будущие модальности (тепловизор, радар, ультразвук, магнитометр, химический сенсор, радиационный сенсор, биометрический сенсор, и т.д.).

## 6. Как добавить новый орган

**Смотри** `docs/11-contributing.md`. **4** шага:

1. **Выбери** слот `24..54`.
2. **Реализуй** `bus.Organ` (`Spec`, `InBounds`, `Warmup`, `Process`, `CoolDown`).
3. **Напиши** тест на Zero-GC (`testing.AllocsPerRun == 0`).
4. **Зарегистрируй** через `registry.HotSwap` и Карантин `front`.
