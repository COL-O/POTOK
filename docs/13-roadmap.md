## 2. Этап 2 — Нагрузка (проверка на реальном потоке)

### 2.1. Что делать

Проверить организм на реальном потоке UDP-пакетов:

- 1000 пакетов/сек.
- 10 000 пакетов/сек.
- 100 000 пакетов/сек.

**Что смотреть**:

| Метрика | Что означает |
|---|---|
| `PacketsReceived` | Сколько пакетов принято |
| `PacketsDropped` | Сколько отбраковано |
| `ImpulsesPushed` | Сколько импульсов опубликовано |
| `RingOverrunCount` | Сколько раз кольцо перезаписало непрочитанный слот |
| `BackpressureCount` | Сколько раз polygon/growth пропустили кадр по Epoch Fencing |
| `ChecksumMismatchCount` | Ошибки CRC32 |

**Как проверить**:

1. Написать генератор UDP-пакетов (`tools/loadgen/main.go`).
2. Запустить `make run`.
3. Запустить генератор с разной интенсивностью.
4. Смотреть `/metrics` и `/prometheus` в Grafana.

**Смысл**: организм «держит» нагрузку или «деградирует».

---

### 2.2. Что проверить

- **Zero-GC** на горячем пути (`go test -run=TestZero`).
- **Epoch Fencing** работает (`RingOverrunCount` растёт при нагрузке).
- **Rate Limiter** prefetch не «захлёбывает» шину.
- **`VetoMask`** «блокирует» опасные модели.

## 3. Этап 3 — Сценарии (проверка на реальных сбоях)

### 3.1. Сценарий 1 — `UDP` → `Surprise` → `polygon` → `growth` → `stratos` → `front` «рефлекс»

**Что делает**: полный цикл жизни организма на реальном потоке.

**Шаги**:

1. UDP-пакет с аномалией (выход за границы KAN).
2. `front` «видит» `Surprise`.
3. `polygon` «диагностирует» (`MatrixProfile` → `KAN` → `CfC`).
4. `growth` «эволюционирует» (`SINDy` → `LUTKAN` → `Adversarial Replay`).
5. `stratos` «записывает» закон (WAL).
6. `front` «прошивает» рефлекс (Карантин → RCU).
7. Повтор события → `front` «отрабатывает» как рефлекс.

**Что смотреть**: `/metrics` показывает `Surprise=1`, `Diagnosed=1`, `EvolvedLaws=1`, `LawsRecorded=1`.

---

### 3.2. Сценарий 2 — `VetoMask` на реальном сбое

**Что делает**: проверка контура боли.

**Шаги**:

1. UDP-пакет с `TTS=0` (авария).
2. `front` «видит» аварию.
3. `polygon` «ставит» `VetoTemporary` (`ReasonCode=5002`).
4. `front` «блокирует» `BitMCTS`.

**Что смотреть**: `/metrics` показывает `VetoIssued=1`, `VetoBlocked=1`.

---

### 3.3. Сценарий 3 — `Prefetch` на реальном дрейфе

**Что делает**: проверка упреждающего прогрева.

**Шаги**:

1. UDP-пакет с дрейфом HDC (`Similarity` падает с 0.98 до 0.80).
2. `front` «видит» дрейф.
3. `GraphPrefetcher.HintDrift` «прогревает» модели `polygon` (`MADV_WILLNEED`).
4. Если дрейф «погас» — `GraphPrefetcher.Cancel` «выгружает» страницы (`MADV_DONTNEED`).

**Что смотреть**: `/metrics` показывает `PrefetchCount`, `EvictCount`.
