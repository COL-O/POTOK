# 10 — Примеры (Профили организма)

**`examples/simple/`**, **`examples/drone/`** — живые примеры, показывающие, как базовое ядро из 24 органов делится под конкретную прикладную задачу (КОН 8: деление, не строительство).

**КОН**: КОН 8 (деление, не строительство) — новый профиль «делится» от базового ядра, а не «строится» с нуля. КОН 10 (честность) — примеры «показывают» факт работы.

---

## 1. `examples/simple/main.go` — Минимальный старт организма

**Что демонстрирует**: базовый такт `Publish` → `Step` → `Verdict`, штатное узнавание и честный флаг `Surprise` (КОН 10).

**Задействованные слои**: `bus` + `front` (3 органа: `HDC`, `Tsetlin`, `Pasport`).

**Дорожки Шины**: `LanePulse` (0), `LaneHDC` (1).

**Ключевое**:
- Минимальная шина (256 слотов).
- `HDC` узнаёт эталонный паттерн (`ClassID` = 1, `BaseMask` = `BaseRoutineMask`).
- `Tsetlin` добавляет `BitPasport`, `ActionCode` = 42.
- Два такта: знакомый импульс (`Status=1`, `Action=42`) и неизвестный импульс (`SurpriseCount=1`).

**Команда запуска**:

```bash
go run ./examples/simple/main.go
```

**Ожидаемый вывод**:

```
Знакомый импульс: Status=1, Action=42, Confidence=0.99
Неизвестный импульс: Status=3, Surprises=1
```

**Смысл**: минимальный организм «живёт» за 40 строк.

## 2. `examples/drone/main.go` — Профиль автономного дрона

**Что демонстрирует**: подключение доменного 25-го органа (`DroneAcousticOrgan`, слот ID = 24) к аудиодорожке `LaneAudio` и связку с графовым обходом `D* Lite` и разведкой `MCTS` (КОН 8).

**Задействованные слои**: `bus` + `front` (6 органов + 25-й `DroneAcoustic`).

**Дорожки Шины**: `LanePulse` (0), `LaneHDC` (1), `LaneGraph` (2), `LaneAudio` (8).

**Ключевое**:
- `DroneAcousticOrgan` — анализирует PCM16-поток с микрофонов дрона.
- `ShockThreshold` = 15000 — порог акустического удара.
- `droneMask` = `BaseRoutineMask` | `BitDroneAcoustic` | `BitDStarLite` | `BitMCTS`.
- Два такта: спокойный полёт (`peak` 3200 < 15000) и акустический удар (`peak` 24000 ≥ 15000 → `ActionCode=707`).

**Команда запуска**:

```bash
go run ./examples/drone/main.go
```

**Ожидаемый вывод**:

```
[Полёт 1] Штатный режим: Status=1, Confidence=0.92, Вызовов DroneAcoustic=1
[Полёт 2] Акустический удар: ActionCode=707 (Уклонение), Confidence=0.96, NextMask=0x30
```

**Смысл**: организм «делится» под задачу дрона, не «строится» с нуля.

## 3. `examples/README.md` — Оглавление примеров

**Что внутри**: карта доступных сценариев, команды запуска, «как добавить свой профиль».

**Карта сценариев**:

| Профиль | Путь | Задействованные этажи | Дорожки Шины | Что демонстрирует |
|---|---|---|---|---|
| **Simple** (Минимальный старт) | `examples/simple/main.go` | `bus` + `front` (3 органа) | `LanePulse` (0), `LaneHDC` (1) | Базовый такт `Publish -> Step -> Verdict`, штатное узнавание и честный флаг `Surprise` |
| **Drone** (Автономный дрон) | `examples/drone/main.go` | `bus` + `front` (6 органов + 25-й `DroneAcoustic`) | `LanePulse` (0), `LaneHDC` (1), `LaneGraph` (2), `LaneAudio` (8) | Подключение доменного 25-го органа к аудиодорожке и связка с обходом препятствий `D* Lite` и `MCTS` |
| **Full Organism** (Полный цикл) | `cmd/organism/main.go` | Все 4 этажа (`front` + `polygon` + `growth` + `stratos`) + HTTP Dashboard | Все 10 дорожек + `SHA-256` WAL на NVMe | Полная спираль жизни: рефлекс → `Surprise` → диагноз → эволюция закона → стресс-тест на «чёрных лебедях» → реабилитация `VetoMask` → живой дашборд `/metrics` |

**Команды запуска**:

```bash
# Минимальный рефлекторный контур
go run ./examples/simple/main.go

# Профиль автономного дрона
go run ./examples/drone/main.go

# Полный 4-этажный живой организм с HTTP-дашбордом
go run ./cmd/organism/...
```

**Как добавить свой профиль** (например, `examples/transport/`):
1. Выберите нужные дорожки Шины (`LaneGraph` для маршрутов, `LaneTensor` для потоков датчиков, `LaneVector` для семантики).
2. При необходимости добавьте специализированный орган в слоты `24..31` по инструкции из `CONTRIBUTING.md`.
3. Соберите `OrganRegistry` только из тех органов, которые нужны вашей задаче — остальные останутся спящими и не займут ни одного байта в горячем кэше CPU.

**Смысл**: примеры — «карта» для разработчика. Он видит, как организм «делится» под задачу.
