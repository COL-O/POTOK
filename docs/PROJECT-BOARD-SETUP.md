### Виды (Views)

1. **Доска** — Board, группировка по Status (канбан круглого стола).
2. **План** — Table: Title, Status, Соратник, Приоритет, Факт, Target date.
3. **Календарь** — Roadmap по Start date → Target date.

### Автоматика (Workflows проекта)

- Item added → Status = `Принято`.
- Issue closed → Status = `Решено`; PR merged → Status = `Решено`.

## Командный путь для Русла (gh)

```bash
gh auth refresh -h github.com -s project        # скоуп project для PAT основателя
gh project list --owner COL-O                    # найти номер «Круглый стол ПОТОКА»
gh project field-create <N> --owner COL-O --name 'Соратник' --data-type SINGLE_SELECT --single-select-options 'Основатель,Сфера,Синтез,Русло,Круг'
gh project field-create <N> --owner COL-O --name 'Этаж' --data-type SINGLE_SELECT --single-select-options 'Дом,Смысл,Фронт,Полигон,Рост,Страто,Сеть'
gh project field-create <N> --owner COL-O --name 'Приоритет' --data-type SINGLE_SELECT --single-select-options 'Высокий,Средний,Низкий'
gh project field-create <N> --owner COL-O --name 'Факт' --data-type TEXT
gh project item-add <N> --owner COL-O --url https://github.com/COL-O/POTOK/issues/5
gh project item-create <N> --owner COL-O --title 'Переезд ленты в Discussions внутри' --body 'После факта живого запуска; исполнитель Русло, голос Сферы ботом.'
# остальные карточки — item-create по таблице выше; значения полей — gh project item-edit
```

Статус Status в новом проекте создаётся по умолчанию (Todo/In Progress/Done) — переименовать варианты в `Принято/В работе/На проверке факта/Решено/Отложено` в настройках поля.

## Что сделает Сфера после наполнения

- Сверю карточки с `docs/PROJECT-PLAN.md` (файловый план — источник до доски) и отмечу доску основной, файловый план станет архивом этапов.
- Каждое решение круга — карточка в `Решено` + поле Факт ссылкой на лог/CI + метка `решение` в задаче.
