# POTOK — статус проекта

## Что за проект

**Саморазвивающийся, осмысленный организм внутри Go-сервера, со своей сферой общего поля («Сфера Вернадского»). Система управления системой: 100 заводов в одном общем поле, в безденежной системе, как в одном организме.**

Подробно: `docs/concept/project-meaning.md`.

## Текущий этап

**Проектное описание поступает в обратном порядке — от окончания к началу.** Поступили: реестр моделей (7 органов), смысл проекта, слои `polygon`/`growth`/`stratos` и финал-скелет с реализацией. Скелет воплощён в коде (`go run .`, `go test ./...`); фундамент (`core` — 6 файлов, `contracts` — 8 файлов, `seed.go` с validateDAG) приведён к авторскому составу. Следующие части дадут середину и начало (формулировки КОНов, концепты, Parquet).

## Что зафиксировано концептуально

- Организм один, 4 слоя по времени: `front` (Рефлекс, нс–мс), `polygon` (Иммунитет, минуты–часы), `growth` (Рост, часы–дни), `stratos` (Память, годы–века).
- Решения слоёв — не голосование, а иерархия аспектов; спор моделей решается прецедентом из `stratos`.
- Продукты слоёв: polygon → антитело для front; growth → почка/прецедент в stratos; stratos → прецеденты всем, учит, но не командует.
- Первая волна — 21 позиция в 4 слоях; полный реестр (заявлено 55) — энциклопедия на потом.
- Исполнение смешанное: часть моделей нативно (Go), часть через ONNX/C, тяжёлые — через GPU.
- TTL / Capacity / Pasport / SHA-256 — механизмы слоёв, а не модели.
