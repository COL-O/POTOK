## Подготовка к первому запуску — сделано

- Снят дубль `Factory` в `contracts` (пакет не собирался).
- Убран неиспользуемый импорт `time` в `modules/growth/router.go` (блокер компиляции).
- Статическая ревизия всех пакетов: дубли типов/функций и неиспользуемые импорты не найдены (кроме закрытых выше).
- `go.sum` создан и сверен с независимым источником.

## Осталось до/после первого запуска

1. Первый живой прогон: `./bootstrap.sh --check` на машине с Go 1.21+ (в песочнице Go нет). Лог ошибок разбирается точечно по файлу/сигнатуре.
2. Известные стыки, которые покажет/не покажет первый прогон (зафиксированы, не чинены без факта):
   - арены тензоров/графов пишутся с `seq=0`, а `ViewFor` сверяет эпоху — после оборота кольца возможен `ErrEpochMismatch`;
   - у `EventHeader` нет смещения аудиодорожки → `TickView.Audio` пуст, `DroneAcoustic` через роутер получит `InBounds=false` (в примере орган вызывается напрямую);
   - `core/registry.StartAll` создаёт отдельную шину на модуль; отписка в `core/eventbus` сравнивает адреса разных переменных.
3. Сверка двух раскладок (`modules/` vs `flat/`) и выбор основной — отдельным решением.
4. Слияние полной ветки в `main` — отдельным решением, не автоматически.
5. Точные формулы (TTS, клиринг, KAN) — позже, сверх синтетики не выдумываем.

## Как запустить

```bash
./bootstrap.sh --check   # проверка структуры + тесты + сборка
make run                 # организм с HTTP-дашбордом :8080
make simple              # минимальный пример
make drone               # профиль дрона
```
