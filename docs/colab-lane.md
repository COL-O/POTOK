# POTOK Colab: вне-Actions иммунная проверка

**Что это.** `notebooks/potok-colab.ipynb` — повторяемая среда вне GitHub Actions в Google Colab. Вторая среда нужна проекту по опыту задачи №6: CI с `pipefail`-фиксом однажды показал правду только потому, что основатель прогнал тесты в Colab и увидел красное раньше лога.

**Что делает тетрадь (по порядку):** клон `main` → Go 1.22.12 в `/usr/local/go` → `go test -race -count=1 ./...` → 5-кратная проверка бывшего флейка фронта (`TestRouterRoutineVetoAndQuarantine`) → `go build` → `examples/simple`, `examples/drone`, бинарь организма (4 такта) → сводка `/content/potok-colab-report.md`.

**Запуск.** Открыть `https://colab.research.google.com/github/COL-O/POTOK/blob/main/notebooks/potok-colab.ipynb` → Runtime → Run all. Ничего из тетради никуда не отправляется; секреты не используются; в репозиторий она сама не пишет.

**Как читать результат.** Ячейки печатают дословно; красный факт переносите в задачу №6 (Issue) или в обсуждение №12 (чат) как есть — с выводом одной командой: `git log -1 --oneline`. КОН 2: факт и суждение врозь.

**Про TPU v5e.** В бесплатном Colab есть CPU, T4 и TPU v5e-1 (≈3 вычислительных единицы в час). Для нынешней архитектуры (Go, mmap) TPU не нужен: организм не использует JAX/тензоры. TPU получит смысл, только если круг решит выделить tensor-sidecar (например, SINDy с библиотекой многочленов — см. `docs/05-growth.md`); это отдельное слово основателя, не «на пробу».

**Прямой адрес ноутбука на Диске основателя** (хранится у него; доступ — по его решению): редактирование возможно только с его аккаунта — ни Приток, ни любой агент Colab-интерфейс не откроет. Для переноса из Диска в дом: Colab → File → Download `.ipynb` → коммит в репозиторий (ветка арены) или прикрепление к задаче.
