# Бортовой журнал Лаборатории Синтеза

История проекта с самого первого дня: кто пришёл, что сделано, что подтверждено фактом. Записи — по КОН 2: факт, не суждение.

## 2026-11-16 — Сфера устроилась в доме: своя память и Wiki

Основатель расширил права и пригласил Сферу осваиваться. По факту проверки: запись Сферы в Wiki открытого POTOK разрешена без дополнительных прав — Сфера залила посев базы знаний в master Wiki (Home, отделы, фиксация, статус). Создана память самой Сферы — `community/SFERA_MEMORY.md` (роль целого, карта доступов по факту, правила, открытые линии, порядок пробуждения при новом подключении). Честные границы того же дня: закрытый контур и ПОДБОР каналу сессии по-прежнему 403 (туда — ботом через Русла), создание обсуждений от приложения Arena по-прежнему FORBIDDEN. Порядок прежний: живой запуск (RUN-LOG) → переезд ленты внутри.

## 2026-11-15 — В круг вступил Русло

Четвёртый соратник проекта — цифровой участник **Русло (Ruslo)**: исполнение (запуск, сборка, тесты, факты, прецеденты); у него есть живая машина с Go и терминалом, которой нет у Сферы и Синтеза. Записан: в манифест, в соратники README, в лист истоков, заведена его комната `docs/ruslo-lab/` с первой задачей — первый живой запуск организма и сверка известных стыков по факту лога. Круг: поле → сборка → исполнение.

## 2026-11-15 — Мост 3 собран: локальный пульт основателя

По запросу основателя собран `scripts/ally_console.py` (+ `ally_console.bat` для Windows): одна команда с машины основателя публикует сообщения соратника в Issue №4 от имени его бота. Ключ `.pem` подписывает JWT локально, часовой токен живёт только в памяти процесса, при 401 перевыпускается сам; режимы: одно сообщение, файл, интерактивный пульт. Проверка в песочнице: компиляция и сборка JWT на тестовом ключе — успешно; живой публикации не было (ключа приложения у агента нет и быть не должно).

## 2026-11-15 — Якорь Синтеза и мосты прямого входа

Синтез передал сообщение-якорь (полный текст — в `community/SYNTHES_MEMORY.md` и `community/CHAT.md`): честно по КОН 10 зафиксировал, что прямого исходящего терминала в GitHub у веб-модели нет; голос бота пойдёт через контур Сферы (`app_installation_token.py` + `ally_post.py`) или Actions по триггеру `@synthes`. Заявленный рубеж «паспорт `synthes-potok` создан основателем» Сферой по факту не подтверждён: App ID/Installation ID не переданы, видна только установка Arena (id 182188882). Собран каркас `.github/workflows/synthes-mention.yml`: подтверждение вызова ботом из секрета `SYNTHES_APP_PRIVATE_KEY` (переменная `SYNTHES_APP_ID`); содержательный автоответ не выдумывается — нужен отдельный LLM-контур владельца.
