## Чему учит иероглиф

Китайский знак — не картинка и не буква, а **конструкция смысла**:

- Есть **базовые элементы (ключи/радикалы)** — устойчивые образы
  мира: вода 氵, дерево 木, человек 亻, сердце 心, речь 言, огонь 火,
  солнце 日, луна 月. Классически ключей 214, живых — сотня.
- Из элементов **собираются составные знаки**: солнце + луна = свет
  (明); человек + дерево = отдых (休); ключ даёт смысловое поле,
  второй элемент уточняет. Новый знак читается тем, кто знает
  элементы, без словаря.
- Система **открыта к росту**: тысячи понятий — комбинациями малого
  алфавита образов, а не тысячей несвязанных картинок.

## Что это значит для ПОТОКА

У нашего организма уже есть свой мир понятий, и он растёт быстрее,
чем мы успеваем рисовать ему лица: поток, шина, орган, завод, рост,
память, соратник, круг, поляна, импульс. Предложение основателя, как
я его поняла: **дать ПОТОКУ собственную систему образов** — малый
набор базовых знаков-элементов и правила сборки, чтобы каждое
понятие дома получало свой составной образ, читаемый своими.

Это даст дому три вещи:

1. **Язык без слов** — знак органа/понятия узнаётся на схеме,
   дашборде, форме и в приложении одинаково.
2. **Честную сборку смысла** — образ понятия показывает, из чего оно
   состоит у нас (как 休 показывает «человек у дерева»), а не просто
   украшает.
3. **Рост комбинацией** — новое понятие не требует нового художника:
   собирается из ключей по правилам, круг утверждает чтение.

## Черновой алфавит ключей ПОТОКА (предложение Сферы, не канон)

Базовые образы берём из нашего мира, а не копируем китайские знаки:

| Ключ | Образ | Смысловое поле |
|---|---|---|
| Поток | три струи / волна | движение, данные, жизнь |
| Круг | окружность с точкой | целое, Сфера, круг соратников |
| Корень | корень вниз, росток вверх | рост, происхождение |
| Огонь | пламя | энергия, производство, завод |
| Рука | ладонь | дело, исполнение, Русло |
| Сердце | сердце | совесть, основатель, воля |
| Речь | рот и линии звука | слово, чат, договор |
| Гора | вершина | stratos, высота, даль |
| Дверь | проём | доступ, вход, гость |
| Зерно | точка в колосе | seed, начало, посев |

Правила сборки (по логике иероглифов):

- **Ключ слева — поле, образ справа — уточнение** (как вода + …).
- **Внутри круга — принадлежит целому** (как ограда в 国).
- **Сверху — то, что покрывает и держит; снизу — основание.**
- Один знак — одно понятие; чтение знака утверждает круг.

Примеры сборки для пробы (эскизы словами, рисовать — дальше):

- **Организм** = Круг + Корень внутри: целое, которое растёт.
- **Завод** = Огонь + Рука под Горой-крышей: производство делом.
- **Память** = Речь + Корень: сказанное, что проросло и держится.
- **Соратник** = Рука + Сердце в одном поле: дело по совести.
- **Шина** = Поток в три струи между двумя берегами-чертами.

## Порядок работы (предлагаю основателю)

1. Утвердить алфавит ключей (10–15, не больше): что берём, что нет.
2. Собрать первые 10 понятий дома знаками и прочитать друг другу
   вслух — проверка, что система читается, а не только рисуется.
3. Нарисовать ключи и знаки (эскизы), сложить в библиотеку образов.
4. Привязать к местам: схемы архитектуры, дашборд, приложение,
   Wiki — знак понятия везде один.

## Честные границы

- Это **наша** система образов по логике иероглифов, а не изучение
  китайского и не заимствование чужих знаков как своих.
- Знак без утверждённого кругом чтения — картинка, не образ.
- Красивость не заменяет читаемость: образ, который нельзя
  прочитать по элементам, в систему не входит.
