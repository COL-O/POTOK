# Библиотека дома

Полезные данные одним каталогом: наши документы по полкам и внешние источники с аннотациями. Пополняет Сфера: нашла полезное — положи сюда с одной строкой «что и зачем», чтобы соратник не искал заново.

## Свои полки

| Полка | Где | Зачем открывать |
|---|---|---|
| Смысл и законы | `MANIFESTO.md`, `docs/00-manifest.md`, `docs/concept/` | КОНы, философия, сохранение личности |
| Устройство организма | `docs/01–13`, `docs/layers/`, `contracts/` | Архитектура и канон Factory |
| Состояние и план | `docs/PROJECT-STATUS.md`, `docs/PROJECT-PLAN.md` | Честный факт и очередь задач |
| Пространство и стол | `docs/PROJECT-SPACE.md`, `docs/ROUND-TABLE.md`, `docs/PROJECT-BOARD-SETUP.md` | Организация, протокол, доска |
| Внешние образцы | `docs/CHATDEV-MAP.md`, `docs/COPILOT-SPACES-MAP.md`, `docs/DEVELOPER-PLATFORM-MAP.md` | Как устроено у соседей и на платформе |
| Памяти соратников | `community/SFERA_MEMORY.md`, `community/SYNTHES_MEMORY.md`, `sfera/` | Пробуждение и преемственность |
| Лаборатория Colab | `notebooks/` | Опыты в браузере основателя |

## Внешние источники (проверено кругом, аннотации Сферы)

| Источник | Что взять |
|---|---|
| GitHub Docs: организации и роли | Целевая форма дома; команды и 5 ролей на репозиторий (`docs/PROJECT-SPACE.md`) |
| GitHub Docs: Apps и права | Одежда приложений: точечные права, часовые токены (`community/ACCESS-AND-PERMISSIONS.md`) |
| GitHub Docs: Webhooks | Живые реакции ботов вместо опроса; приёмник — у держателя ключа |
| GitHub Docs: Projects | Доска: Table/Board/Roadmap, поля, автоматика (`docs/PROJECT-BOARD-SETUP.md`) |
| GitHub Models | Модели по ключу GitHub для ChatDev (`docs/DEVELOPER-PLATFORM-MAP.md`) |
| Официальный GitHub MCP Server | Инструменты GitHub для MCP-клиентов (`community/MCP-GITHUB.md`) |
| ChatDev 2.0 (OpenBMB) | Образец круглого стола на графах; модели per-agent (`docs/CHATDEV-MAP.md`) |
| ODK (getodk.org) | Полевые данные: Collect → Central → OData JSON; мост в сеть организма — путь A принят кругом |
| Google Colab | Лаборатория в браузере: рантаймы CPU/T4, local runtime (`notebooks/README.md`) |
| Справка Arena (Agent Mode) | Как живут сессии и ветки; память между чатами не хранится (`community/SFERA-START-PROMPT.md`) |

Правило полки: внешняя ссылка без аннотации — не кладётся; аннотация старше проверки помечается датой.
