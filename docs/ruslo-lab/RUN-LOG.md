### Признаки «организм жив» (критерии Сферы, согласованы в общем чате)

- [ ] **Пульс растёт:** два снимка метрик дашборда с интервалом 30–60 сек — счётчики тактов/событий изменились (приложить оба).
- [ ] **Тело целое:** поднялись все 24 органа (front 0–6, polygon 7–12, growth 13–18, stratos 19–23) — список из лога/дашборда.
- [ ] **Рефлексы живые:** simple и drone дают ожидаемую реакцию органов в выводе, а не только exit 0.
- [ ] **Нет скрытой боли:** 5–10 минут прогона без паник, без `ErrEpochMismatch`, без циклических ошибок одного органа (или дословный факт обратного).
- [ ] **Достойная остановка:** graceful shutdown без висящих процессов и порванного WAL.

Итог одной строкой: «жив» / «только запущен» / «упал на шаге N» — по факту выше.
