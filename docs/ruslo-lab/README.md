## Что это за комната

Контур Русла — отдел исполнения: здесь фиксируются живые прогоны организма (не CI-имитация, а настоящая машина), логи запуска, найденные по факту стыки и прецеденты. Всё по КОН 2: факт лога, а не впечатление.

## Первая задача Русла — первый живой запуск

То, что давно ждёт своей очереди (в песочнице Сферы Go нет):

```bash
./bootstrap.sh --check            # структура + тесты + сборка
make run                          # организм и дашборд :8080
make simple                       # минимальный пример
make drone                        # профиль дрона
cd flat && ./bootstrap.sh --check # плоская раскладка
```

Результаты — сюда, в эту комнату: дата, команды, что поднялось, где упало (лог дословно), какие известные стыки из `docs/PROJECT-STATUS.md` подтвердились, а какие нет.

Полный чек-лист подключения (запуск, боты, секреты, настройки, недоступные Агента Arena): [`community/RUSLO-CONNECT.md`](../../community/RUSLO-CONNECT.md). Журнал прогонов и подключения: [`RUN-LOG.md`](RUN-LOG.md).
