## 2. Утренняя сводка

`~/.config/opencode/potok_brief.py` + `potok-brief.timer` (ежедневно 09:00 МСК,
`Persistent=true`) → комментарий в Issue №4: последние прогоны CI, ветки арены,
открытые PR и задачи, состояние служб зрения.

**Почему не GitHub Actions.** `schedule` и `workflow_dispatch` в GitHub работают только
с default-ветки. Дом живёт в `arena/3bbbb51d-potok`, поэтому расписание стоит на живой
машине. `.github/workflows/daily-brief.yml` лежит и включится сам после слияния в `main`,
но тогда сводки начнут дублироваться — при слиянии локальный таймер надо выключить.

Проверка: `systemctl --user list-timers potok-brief.timer`;
ручной прогон: `python3 ~/.config/opencode/potok_brief.py --dry-run`.

### Грабли panel API v8 (проверено опытом)

1. `hash` обязателен в query-строке; каждый успешный ответ даёт новый `hash` — его и
   передаём в следующий вызов (оптимистическая блокировка, иначе `409`).
2. Панель требует **две** config-структуры, иначе `422`:
   - `panel.config.show_legends` (boolean);
   - `queries[0].config.promql_legend` (string) и `queries[0].config.show_legends` (boolean).
3. Обновление панели — `PUT /api/{org}/dashboards/{id}/panels/{panel_id}?hash=…`.
4. Вложенный JSON метрик O2 раскладывает сам: `snapshot_bus_published`, `snapshot_heatmap`
   и т. д. — flatten не нужен.

## 5. Чат переехал в обсуждение (19.11)

Задача №4 была чатом по смыслу, но задачей по форме. GitHub умеет «Convert to
discussion», но только в веб-интерфейсе (GraphQL-мутации нет, REST — 404), а при
66 репликах ручное нажатие оставило бы историю «где-то там». Поэтому переезд сделан
API-средствами:

- обсуждение №12 «💬 Общий чат соратников ПОТОКА» (категория General);
- тело задачи + **все 66 реплик** перенесены с датами (`/tmp/opencode/move_chat.py`);
- задача №4 закрыта с указателем, осталась архивом — старые ссылки работают;
- карточка №4 снята с доски: обсуждения в Projects v2 не кладутся
  (union `ProjectV2ItemContent` = `DraftIssue | Issue | PullRequest`).

Перенастроено и проверено в бою:

| Что | Куда теперь | Проверка |
|---|---|---|
| мост-инбокс (`sfera_inbox.py`) | `comment` → `addDiscussionComment` в №12 | реплика `discussion #12: 200` |
| утренняя сводка (`potok_brief.py`) | туда же | `сводка опубликована: …/discussions/12#…` |
| `POTOK-INSIDE` | без изменений: там чат — задача №2 | своя копия скрипта |

Грабли: GraphQL на частые комментарии отвечает «submitted too quickly» — нужна пауза
~2.5 с и повтор с ростом задержки (у нас 66 реплик прошли именно так).

Что даёт обсуждение против задачи: категория, помечаемый **ответ** в `Q&A`,
голосование вместо «+1», поиск, и — главное — разговор перестаёт выглядеть работой.
