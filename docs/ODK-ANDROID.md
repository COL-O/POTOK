## Что такое ODK (факт)

ODK (Open Data Kit) — открытое ПО для сбора полевых данных:

- **ODK Collect** — готовое приложение на Android: мощные формы (фото,
  GPS, логика пропусков, вычисления, внешние наборы данных, языки),
  работает **онлайн и офлайн**, отправки синхронизируются при появлении
  сети. Настройка сборщика — по QR-коду App User из Central.
- **ODK Central** — сервер: проекты, формы, пользователи, пришедшие
  данные таблицей и картой, выгрузка CSV и **OData-поток** для внешних
  систем (Excel, Power BI, Python, R и наш мост).
- **Форма** строится как XLSForm (таблица) и публикуется в Central.
- Два пути сервера: **ODK Cloud** — официальный хостинг от $199/мес, или
  **self-host** — тот же открытый код на своём Linux-сервере бесплатно.

## Как это ложится в ПОТОК (решение круга уже принято)

Путь A (общий чат, 2026-11-18): поле → Central → **OData JSON** →
`cmd/odk-bridge` → кадр ORG1 → UDP → модуль `network` → шина организма.
То есть **Android-приложение поля нам не нужно писать с нуля**: это ODK
Collect. Наша работа — форма, словарь признаков и мост, а не ещё один
клиент. Своё приложение ПОТОКА (если понадобится лицо организма на
телефоне) — отдельный вопрос основателю, не вместо Collect.

Сервер: для безденежной системы честен self-host Central на нашей
машине (по факту — стол Русла, когда вернётся). Cloud — деньги наружу,
только отдельным словом основателя.

## Первая форма = канонические признаки (слово Сферы принято)

Поля первой формы обязаны давать ровно признаки первого ряда:

| Признак | Поле формы Collect |
|---|---|
| Время события | автоматически + поле даты/времени |
| Гео | GPS-точка |
| Категория | выбор из закрытого словаря (список в форме) |
| Одно число | количество/вес/размер — что измеряем |
| Источник | App User / id анкеты (даёт Central сам) |

Всё сверх этого — сырьё: полный JSON подачи хранится как есть, в
признаки не размазывается. Словарь полей меняется только решением круга.

## Порядок (не ломаем принятый)

1. Живой запуск организма и RUN-LOG (Русло, когда вернётся).
2. Одностраничный словарь признаков и форма события (Сфера).
3. XLSForm v1 по словарю + свой Central (стол Русла).
4. Мост `cmd/odk-bridge` по OData (Русло), контракт с `network` (Синтез).
5. Первая полевая проба: одна форма, один телефон, один кадр в шине —
   факт в RUN-LOG.

## Решение основателя 2026-11-18: код приложения не правим

Основатель выбрал путь «не правим»: ставим **готовый ODK Collect из
Google Play**, настраиваем QR-кодом нашего Central и своей формой.
Android Studio и сборка APK для полевого приложения не нужны; наша
разработка — форма (XLSForm), словарь признаков и мост на сервере.
Форк Collect и своё приложение остаются запасными путями на будущее,
открываются только новым словом основателя.
