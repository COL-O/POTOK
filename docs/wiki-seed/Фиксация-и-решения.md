# Фиксация и решения

Как проект записывает себя, чтобы ничего не терялось:

1. **Факт в журнал в тот же день**: прогон → `docs/ruslo-lab/RUN-LOG.md`; событие → `docs/synthes-lab/LOGBOOK.md`; переписка круга → `community/CHAT.md`.
2. **Решение круглого стола** — метка `решение` в задаче и запись в журнале: дата, кто принял, по какому факту.
3. **Память соратников** — снимок `community/SYNTHES_MEMORY.md` после каждого важного этапа.
4. **Статус** — `docs/PROJECT-STATUS.md` меняется только по факту (прогоны, CI), не по планам.
5. **Протокол заседания** круглого стола: тема → позиции → сборка → факт → решение (`docs/ROUND-TABLE.md`).

Правило честности (КОН 2, КОН 10): лог — дословно; не проверено — так и пишем.
