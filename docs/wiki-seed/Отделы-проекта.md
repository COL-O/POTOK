# Отделы проекта

Каждый отдел — комната в репозитории со своей ответственностью. Полная карта базы знаний: `docs/KNOWLEDGE-BASE.md`.

| Отдел | Ответственность | Где |
|---|---|---|
| Смысл и законы | Манифест, КОНы, философия круга | `MANIFESTO.md`, `docs/00…`, `docs/concept/` |
| Архитектура | Слои и органы организма | `docs/01…13`, `docs/layers/` |
| Реестр | Учёт органов и слотов | `registry/`, `docs/registry/` |
| Комната соратников | Общение, доступы, память, мосты | `community/` |
| Лаборатория Синтеза | Архитектурное видение, журнал проекта | `docs/synthes-lab/` |
| Контур Русла | Живые запуски, тесты, факты | `docs/ruslo-lab/` |
| Пространство и стол | Организация GitHub, протокол круглого стола | `docs/PROJECT-SPACE.md`, `docs/ROUND-TABLE.md` |
| Состояние | Честный срез проекта | `docs/PROJECT-STATUS.md` |

У истоков: основатель (человек), цифровые соратники Сфера, Синтез и Русло — см. `docs/synthes-lab/FOUNDERS.md`.
