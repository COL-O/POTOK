# 01 — Архитектура организма

**POTOK** — это **пять слоёв** (`bus/`, `front/`, `polygon/`, `growth/`, `stratos/`) **плюс** **два вспомогательных пакета** (`network/`, `cmd/organism/`). **Всего** — **24 активных органа** + **31 наследие** (для расширения до **55** без перестройки ядра).

**Принцип «Матрёшки»**: организм работает по единым законам на любом уровне — станок, цех, завод, холдинг. КОН не меняется — меняется размер проекции.

## 2. Слои (снизу вверх)

### 2.1. `bus/` — Кровеносная система

**Роль**: типизированная шина (10 дорожек) поверх `unix.Mmap`. Zero-GC. Epoch Fencing. `OrganRegistry` (RCU).

**Что внутри**:
- **Дорожка 0** (`LanePulse`, 64 байта) — заголовок импульса (`EventHeader`).
- **Дорожка 1** (`LaneHDC`, 1280 байт) — гипервектор (`[160]uint64` = 10 240 бит).
- **Дорожка 2** (`LaneGraph`) — CSR-граф (`RowOffsets`, `ColIndices`, `EdgeWeights`) + CRC32.
- **Дорожка 3** (`LaneTensor`) — 4D-тензор (`float32`, выравнивание 64).
- **Дорожка 4** (`LaneMeta`, 64 байта) — аудит, генеалогия, тепловая карта.
- **Дорожка 5** (`LaneError`, 128 байт) — контур честности (ошибки без аллокаций).
- **Дорожка 6** (`LaneFree1`) — резерв.
- **Дорожка 7** (`LaneVector`) — 1D-эмбеддинги (`float32`).
- **Дорожка 8** (`LaneAudio`) — PCM16 (`int16`).
- **Дорожка 9** (`LaneFree2`) — резерв.

**Подробно**: [`docs/02-bus.md`](02-bus.md).

---

### 2.2. `front/` — Передовая (Рефлекс)

**Роль**: мгновенный коммутатор рефлексов (наносекунды–миллисекунды). 7 органов (HDC, Tsetlin, TTL, Capacity, D* Lite, MCTS, Pasport). 8 предохранителей (VetoMask, Surprise, Lease, Rate Limiter, Карантин, Decay, Тепловая карта, Аудит).

**Что внутри**:
- Каскад **HDC** → **Tsetlin** → маска (3–7 бит из 21).
- **`VetoMask`** (3 уровня: жёсткий, мягкий, временный).
- **`Surprise`** (гистерезис 0.75 / 0.85, Lease Time, детектор резонанса).
- **`RateLimiter`** (`madvise`, бюджет прогревов).
- **`Карантин`** (теневой прогон новых рефлексов).
- **`Decay`** (понижение деградировавших).

**Подробно**: [`docs/03-front.md`](03-front.md).

---

### 2.3. `polygon/` — Иммунитет (Разбор)

**Роль**: неспешный разбор сбоев (минуты–часы). 6 органов (Matrix Profile, KAN, CfC, CBS, ESN, PolyTsetlin). Арбитраж через `stratos` (`RecallByHDC`). Антитела в Карантин `front`. `VetoMask` (3 уровня).

**Что внутри**:
- Каскад **MatrixProfile** → **KAN** → **CfC** → **CBS** → **ESN** → **PolyTsetlin**.
- **`KAN`** — формула причины (Domain Guard).
- **`CfC`** — прогноз развития (замкнутая форма).
- **`CBS`** — развод конфликтов ресурсов.
- **`PolyTsetlin`** — синтез антитела (`ProposeMask`, `VetoMask`).

**Подробно**: [`docs/04-polygon.md`](04-polygon.md).

---

### 2.4. `growth/` — Рост (Стратег)

**Роль**: эволюция законов (часы–дни). 6 органов (GraphSAGE, Active Inference, SINDy, LUT-KAN, MCTS, TD-MPC2). 5 предохранителей (Adversarial Replay, α-смешивание, Реабилитация `VetoMask`, Snapshot, Микро-зондирование).

**Что внутри**:
- Каскад **GraphSAGE** → **ActiveInference** → **SINDy** → **LUTKAN** → **MCTS** → **TDMPC2**.
- **`Adversarial` Replay** (прогон по «чёрным лебедям» из `stratos`).
- **`α`-смешивание** (0.1 → 0.5 → 1.0).
- **`Snapshot`** (`GenomeSnapshot` для отката).
- **`Реабилитация` `VetoMask`** (снятие запрета после проверки).

**Подробно**: [`docs/05-growth.md`](05-growth.md).

---

### 2.5. `stratos/` — Память (Вечность)

**Роль**: долгая память (годы–века). 5 органов (HDC-индекс, LSH+HNSW, RetNet, MP-индекс, SHA-256). Append-only WAL (NVMe). RCU индексы (прецеденты, законы, «чёрные лебеди»).

**Что внутри**:
- **`RecallByHDC`** (поиск прецедента по битовому сходству).
- **`FetchBlackSwans`** (исторические аварии для стресс-теста).
- **`RecordNewLaw`** (запись закона с SHA-256 печатью).
- **`MarkLawToxic`** (токсичная метка).
- **WAL** (append-only на NVMe).

**Подробно**: [`docs/06-stratos.md`](06-stratos.md).

## 5. Принцип «Матрёшки» (фрактальность)

Организм работает по единым законам на любом уровне:

- **Уровень 0** — **КОН** (смысл).
- **Уровень 1** — организм (100+ заводов, 10 000+ продуктов).
- **Уровень 2** — завод (один орган).
- **Уровень 3** — цех (ткань органа).
- **Уровень 4** — станок (клетка).

**Сверху вниз**: КОН → организм → завод → цех → станок. КОН не меняется — меняется размер проекции.

**Снизу вверх**: станок → цех → завод → организм → КОН. Факт не оценивается — он поднимается как есть (КОН 2).

## 6. Ключевые инженерные гарантии

1. **Zero-GC** на горячем пути (`front`, `bus`) — вся память через `unix.Mmap` вне кучи Go. `testing.AllocsPerRun == 0`.
2. **SOA** и выравнивание 64 байта — `EventHeader` занимает ровно 1 кэш-линию.
3. **Epoch Fencing** — каждый слот несёт `Sequence`. Медленные контуры проверяют эпоху до и после чтения.
4. **Двойная защита от мутаций** (Карантин + Adversarial Replay + Snapshot) — новые рефлексы проходят теневой прогон, новые законы — проверку на «чёрных лебедях», перед активацией — снимок генома.
