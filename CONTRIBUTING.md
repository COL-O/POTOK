# Как участвовать в POTOK

**POTOK — открытый проект, часть большого проекта «Свободное общество» (проектное название). Присоединяйтесь — сотрудничество приветствуется.** Участие открыто для всех, кому близок смысл; вопросы, идеи и предложения — через Issues и Pull Requests.

POTOK — единый индустриальный организм. Порядок работы задаёт **КОН 11: КОН → схема → «как»** — сначала смысл, потом схема, потом код.

## С чего начать

1. Прочитайте [`docs/00-manifest.md`](docs/00-manifest.md) — 11 КОНов.
2. Посмотрите [`docs/01-architecture.md`](docs/01-architecture.md) — 5 слоёв и 24 органа.
3. Полный реестр концептов: [`docs/concept/concepts-index.md`](docs/concept/concepts-index.md).

## Как добавить новый орган (КОН 8 — деление, не строительство)

Подробно: [`docs/11-contributing.md`](docs/11-contributing.md). Кратко — 4 шага:

1. Выберите свободный слот `24..54` (реестр: [`docs/registry/models-55.md`](docs/registry/models-55.md), машиночитаемо: [`registry/models.yaml`](registry/models.yaml)).
2. Реализуйте интерфейс `bus.Organ` (`Spec`, `InBounds`, `Warmup`, `Process`, `CoolDown`).
3. Напишите тест на Zero-GC (`testing.AllocsPerRun == 0` на горячем пути).
4. Зарегистрируйте через `registry.HotSwap` и Карантин слоя `front`.

## Проверка перед отправкой

```bash
./bootstrap.sh --check   # тесты с -race + Zero-GC + сборка
```

## Ветки

- `arena/3bbbb51d-potok` — основная полная ветка проекта (вся текущая работа).
- `main` — ранняя неполная версия, хранится для сравнения; напрямую в неё не коммитим.

## Стиль

- Один файл — одно сообщение, сразу в GitHub.
- Текст и смысл авторских файлов не переиначиваем; допустима только техническая чистка артефактов передачи.
- Точные формулы (TTS, клиринг, KAN) — синтетика до отдельного решения; сверх необходимого для сборки не выдумываем.
