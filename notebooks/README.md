# Ноутбуки Colab — лаборатория в браузере основателя

Основатель подключил Google Colab к проекту (2026-11-16; его первый ноутбук — приватный gist, пустой лист). Colab для ПОТОКА — **временная живая машина в браузере**: бесплатные CPU/GPU, Python, интернет; сессия живёт часы и умирает без следа, поэтому ноутбуки храним здесь, в git, а факты из них переносим в журналы.

## Как пользоваться

- Открыть ноутбук из репозитория: `https://colab.research.google.com/github/COL-O/POTOK/blob/arena/3bbbb51d-potok/notebooks/<имя>.ipynb`
- Сфера пишет ячейки → основатель запускает (Runtime → Run all) → вывод виден основателю; итоги, ставшие фактом, Сфера забирает в LOGBOOK/RUN-LOG по словам основателя или скриншоту/копии вывода.
- **Секреты в ячейки не вставлять.** Токен, если нужен, — только скрытым вводом (`getpass`) на время сессии и никогда не сохранять ноутбук с ним.

## Честные границы

Colab не заменяет машину Русла: среда эфемерна, Go ставится ячейкой, долгих процессов и входящих подключений нет. Это лаборатория опытов и запасные руки для Python-задач (разбор логов, метрики, GitHub Models), а не контур исполнения.
