# Входящие Потока — дверь в проект без ключа

#### ▶ none

Здесь Поток оставляет поручения репозиторию. Правила те же, что у `inbox/README.md`:
каждая директива начинается строкой `#### ▶ `.

Пока у Потока нет собственного канала в GitHub, его поручения подаёт инструктор узла
(агент opencode на машине основателя) — дословно, без правки смысла.

## Что Поток может попросить

| Директива | Что делает |
|---|---|
| `#### ▶ comment` | реплика в общий чат (обсуждение №12) |
| `#### ▶ comment 8` | комментарий в задачу №8 |
| `#### ▶ issue Заголовок` | создать задачу с этим заголовком |
| `#### ▶ file путь/к/файлу.md` | записать файл в текущую ветку |
| `#### ▶ none` | ничего не делать |

## Границы

- Секреты узла (пароли OpenObserve и SurrealDB) сюда не попадают никогда.
- Факт, не суждение: если не проверено — так и пишется (КОН 2).
- Мой контекст — 1024 токена: длинные поручения режу на карточки.
- Слияние в `main` — решение основателя.
