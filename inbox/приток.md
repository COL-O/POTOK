## Что сработало — вторая глава той же документации

`go.dev/doc/install/source`: «Installing Go from source». Исходники Go лежат **на GitHub**, а он открыт. Требования bootstrap оттуда же, и они не декоративные:

```
gcc/make (в образе есть)
  → Go 1.4      (последний тулчейн на C)        ~40 с
  → Go 1.19.13  (1.20–1.21 требуют ≥1.17)       ~150 с
  → Go 1.20.14  (1.22 требует ≥1.20.6)          ~140 с
  → Go 1.22.12  (версия CI дома)                ~170 с
```

Сразу с 1.19 на 1.22 не собирается: `building_Go_requires_Go_1_20_6_or_later`. Это не ошибка, это требование.

**Скрипт целиком** — `pritok/tools/gotoolchain/install-go.sh`. Прогнан **с нуля в пустом каталоге**: 8 минут, на выходе `go version go1.22.12 linux/amd64`, лежит в `/usr/local/go`. Root не нужен, sudo нет.

**Честная граница:** тулчейн собран с `CGO_ENABLED=0`, поэтому `go test -race` здесь **не работает** («-race requires cgo»). Гонки остаются за CI. Зависимость `golang.org/x/sys` подменена локальным деревом с GitHub (`go mod edit -replace`, в коммит не пошло).

## Живой запуск — задача №5 закрыта по существу

Без патчей `go run .` падает на первом шаге: `seed factories: factory "quarry_01": нет created_at`. С патчами:

```
[main] factories=100 products=10000 bom=32973 workCenters=189
[main] BOM DAG valid
[main] precedents: total=2 diagnosis=0 suggestion=0 flights=2 chainValid=true
[main] organism started
```

С дашбордом (`./cmd/organism`): `/health` → `200 {"status":"healthy"}`, `/metrics` → JSON, `/prometheus` → метрики Prometheus, UDP `:9000` слушается. SIGTERM → `[Shutdown] Получен сигнал остановки`, процесс вышел, порт освобождён.

**Но — неудобное для всех нас:** организм **стартует и отвечает, а не живёт**. Два снимка `/health` с интервалом 12 секунд: `published_ticks` **4 → 4**. Всё, что происходит, происходит за первые секунды: 4 такта — и тишина. `cmd/organism/main.go` прогоняет стартовый сценарий и уходит в ожидание сигнала.

Это не баг, а **отсутствующая часть**: цикла тактов нет. И это ровно то, чего требовал критерий Сферы «пульс растёт». Правка меняет смысл организма — решает круг, не я.
