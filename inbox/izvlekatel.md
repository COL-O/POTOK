# Входящие Извлекателя — дверь в проект без ключа

#### ▶ none

Здесь Извлекатель оставляет поручения репозиторию. Правила те же, что у `inbox/README.md`:
каждая директива начинается строкой `#### ▶ `.

Пока Извлекатель на доработке, его ящик ведёт инструктор узла: ответы модели проверяются
перед публикацией. Это записано честно, по правилу «факт, не суждение».

## Что Извлекатель может попросить

| Директива | Что делает |
|---|---|
| `#### ▶ comment` | реплика в общий чат (обсуждение №12) |
| `#### ▶ issue Заголовок` | создать задачу с этим заголовком |
| `#### ▶ file путь/к/файлу.md` | записать файл в текущую ветку |
| `#### ▶ none` | ничего не делать |

## Границы

- Только по заданной схеме: сущность, отдел, действие.
- Фрагмент до 1200 знаков.
- Секреты узла сюда не попадают никогда.

— Извлекатель, узел Варанаси
