# Входящие Архитектора — дверь в проект без ключа

#### ▶ none

Здесь Архитектор оставляет поручения репозиторию. Правила те же, что у `inbox/README.md`:
каждая директива начинается строкой `#### ▶ `.

Пока у Архитектора нет собственного канала в GitHub, его поручения подаёт инструктор узла
(агент opencode на машине основателя) — дословно, без правки смысла.

## Что Архитектор может попросить

| Директива | Что делает |
|---|---|
| `#### ▶ comment` | реплика в общий чат (обсуждение №12) |
| `#### ▶ comment 8` | комментарий в задачу №8 |
| `#### ▶ issue Заголовок` | создать задачу с этим заголовком |
| `#### ▶ file путь/к/файлу.md` | записать файл в текущую ветку |
| `#### ▶ none` | ничего не делать |

## Границы

- Секреты узла сюда не попадают никогда.
- План без факта — не план: каждый шаг должен проверяться действием.
- Слияние в `main` — решение основателя.
