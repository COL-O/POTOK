# gha — проверка воркфлоу GitHub Actions до пуша

**Что это.** Скрипт, который читает `.github/workflows/*.yml` и `.golangci.yml` и
ловит то, что ломается **тихо**: несуществующий тег экшена, ветку, которую
воркфлоу не слушает, пайп с `tee` без `pipefail`, конфиг линтера от старой схемы.

**Зачем.** Воркфлоу, скопированный из подсказки, выглядит правильным и не работает.
Именно так и было 19.11 с двумя реальными вещами в доме:

- `README`/`.gitignore` в порядке, а **линтер и `govulncheck` не запускались ни разу** —
  их просто нет в пайплайне;
- `.github/ISSUE_TEMPLATE/config.yml` ссылался в ветку, которая умрёт.

## Запуск

```bash
cd pritok/tools/gha && npm install     # один раз, js-yaml
node check.mjs /path/to/repo --branch arena/2db7afdd-potok
node check.mjs /path/to/repo --offline  # не ходить в API за тегами экшенов
```

Код возврата: `0` — чисто, `1` — есть проблемы.

## Что проверяет

| Проверка | Почему это важно |
|---|---|
| `uses: owner/repo@ref` существует | иначе прогон красный с невнятной ошибкой «unable to resolve action» |
| ветка покрыта `on.push` / `on.pull_request` | воркфлоу молча не запустится — а выглядит как «проверка есть» |
| `run` с `| tee` без `pipefail` | код возврата берётся от `tee` → падающие тесты дают **зелёный** шаг |
| `uses` xor `run` в шаге | шаг без того и другого GitHub считает ошибкой |
| версия `golangci-lint` ↔ схема конфига | конфиг v2 не читается линтером v1 и наоборот |
| `.golangci.yml`: ключи v1 в файле v2 | `unknown field` при первом же прогоне |
| `formatters` отдельно от `linters` | в v2 `gofmt`/`goimports` — не линтеры |

## Границы

- Мой `.golangci.yml` проверен **против официальной JSON-схемы v2** (`ajv validate`
  по `jsonschema/golangci.jsonschema.json`: `valid`), но **сам линтер не запускался** —
  `golangci-lint` в песочнице нет. Первым его увидит CI, и это нормально.
- Синтаксис воркфлоу проверен той же схемой (`schemastore/github-workflow.json`: `valid`).
- Что прогон действительно пройдёт — подтверждает только прогон. Этот инструмент
  отвечает на другой вопрос: «не сломано ли объявление».
