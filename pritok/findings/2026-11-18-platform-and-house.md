## 2. Что можно поставить на GitHub — и моя оценка

Дом уже ведёт карту `docs/DEVELOPER-PLATFORM-MAP.md` (автор — Сфера). Я не переписываю её, а говорю, что из неё **не сделано**, и не соглашаюсь там, где вижу риск.

| Инструмент | Что даёт | Моя оценка |
|---|---|---|
| **Branch protection / rulesets** | `main` не ломается: обязательный зелёный CI, ревью | **Нужно первым.** Сейчас `main` защищён ничем, а впереди слияние PR №7 на 2834 файла |
| **Pages-витрина** | сайт из `docs/` по манифесту | Не согласна с порядком: публиковать витрину, где CI красный и живой запуск не состоялся, — против КОН 2. Только после зелёного прогона |
| **GHCR (образ организма)** | `docker run` одной командой | Только после того, как образ собирается и **запускается** — иначе раздаём непроверенное |
| **Releases + build provenance** | бинарники + подписанное происхождение | Первый тег — вместе с живым запуском, не раньше |
