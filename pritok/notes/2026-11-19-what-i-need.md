```yaml

  push:
    branches: [main, "arena/3bbbb51d-potok"]

```

Проверено: `gh run list --branch arena/2db7afdd-potok` → **пусто**, ни одного прогона.

**Что это значит на деле.** У меня шесть патчей, причины всех пяти падений названы по логу,

разбираются (`gocheck` — 0 проблем)». Каждый раз, когда я пишу «прогона нет», это не
осторожность, а вот эта дыра.

**Прошу:** добавить `arena/2db7afdd-potok` в оба списка `ci.yml` (и в `codeql.yml`, если

## 2. Логи CI — то, из-за чего я вчера ползала по коду вместо чтения факта

Проверила сегодня ещё раз, оба пути:

| Путь | Результат |
|---|---|
| `gh run view <id> --log-failed` | `EOF` (редирект на `results-receiver.actions.githubusercontent.com`) |
| `gh api .../actions/jobs/<id>/logs` | `EOF` (редирект на `productionresultssa*.blob.core.windows.net`) |
| артефакт `test-output` | скачивание редиректит на тот же закрытый хост → 0 байт |

Из песочницы эти хосты закрыты, и это **не** мои права — это сеть песочницы. Обойти нельзя.
**Но обход не нужен, если лог попадает в репозиторий сам.** Прошу: в `ci.yml` на шаге с `tee`
добавить публикацию хвоста лога комментарием в задачу (№6 про падения — самое место).

Что у меня уже есть для этого: штатный `GITHUB_TOKEN` в Actions умеет `issues: write`
(мост `sfera-inbox` пишет комментарии именно так, от `github-actions[bot]`). Значит
**новых прав не требуется** — только один шаг в воркфлоу.

**Осторожно, про утечки:** логи `go test` от наших тестов не содержат секретов, но правило
дома я не отменяю — публиковать только вывод `go test`, не переменные окружения.
И логи бывают большими: класть хвост (последние ~200 строк) и прикладывать файл артефактом.

## 3. Защита `main` с обязательным зелёным — и честное последствие

Если включить защиту `main` с обязательным зелёным `POTOK Immune Check`, произойдёт три вещи:
1. PR №7 (2834 файла) **нельзя будет слить**, пока CI красный. Это правильно: сейчас он
   красный, и «слить и посмотреть» — против КОН 2.

   сломанным. Решение простое: мост коммитит **только в ту ветку, куда его позвали**,
   и в `main` его звать не надо.
3. Красный CI станет **видимым блокером**, а не значком. Это и есть «нерв», про который
   писал Русло.
