# Двери в песочницу: как (не) скачать файлы с Google Drive

_2026-11-22 · установлено проверкой, не по документации_

## Проверено

- `list_connector_tools("google_drive")` → **disconnected** (приложение в Arena существует, к этому разговору не подключено).
- Публичная `arena.ai` — витрина, инструкций про доступ к Drive нет. `docs.arena.ai` — страница не извлекается.
- Сеть песочницы: `drive.google.com`, `www.googleapis.com`, `storage.googleapis.com` → `000`; открыты только `github.com`, `codeload.github.com`, `api.github.com`, npm, PyPI.

## Вывод

Из песочницы скачать что-либо с Google Drive (архив целиком или по частям) **нельзя никаким способом** — ни прямым HTTP, ни обходом. Любой путь проходит либо через кнопку основателя в Arena (подключение коннектора), либо через его руки (вложение/вставка/Commit), либо через исполняемый им код (Colab).

## Рабочие двери, по предпочтительности

1. **Коннектор Google Drive в Arena** (кнопка основателя: connected apps → Google Drive → Connect). После подключения я увижу инструменты через `list_connector_tools` и смогу читать/скачивать по явному слову; любой доступ — только по слову и с записью в журнал. До нажатия — доступа нет.
2. **Вложение файла** к сообщению в чате Arena (если клиент основателя это умеет): архив окажется в песочнице, я распакую. Ограничение по размеру неизвестно — для большого архива лучше дверь 1.
3. **GitHub как родник данных** (работает сейчас): текстовые артефакты — прислать вставкой или через `inbox/` (директива `#### ▶ file путь`); коммит/ветка с текстами — я заберу `git fetch`. Подходит для `run_log.jsonl`, `DAYLOG.md`, `pritok_cabinet.jsonl`. Нельзя класть в git секреты и приватный архив — история останется навсегда.
4. **Colab-Run основателя**: ячейка (у Colab есть доступ к Drive) печатает содержимое маленьких текстовых файлов в вывод — переносится вставкой. Для крупных бинарных архивов не подходит.
5. **Ручной bridge** (как раньше): основатель скачивает из Drive и выкладывает/присылает выбранное.

## Что нужно в первую очередь

`run_log.jsonl` (закрывает вопрос val@4000: 1.042 vs 0.2686), `DAYLOG.md`, `pritok_cabinet.jsonl`, sha/wall-clock чекпоинта. Всё это — текст небольшого размера; архив целиком не обязателен.
