# Словарь действий круга

По слову основателя 2026-11-20: английские технические глаголы в речи напрямик подменяются русскими, чтобы смысл действия читался человеком, а не инструментом. «Мержи» — под запретом: звучит как «моржи».

| Слово | Действие | Инструмент |
|---|---|---|
| **состыкуй** (ветку N / PR N) | Слияние ветки/PR в `main` обычным merge-коммитом | `gh pr merge N --merge` |
| **убери** (ветку) | Удаление отмершей ветки после состыковки | `git push origin --delete <ветка>` — только по слову основателя |
| **останови** (ветку) | Архивировать/отложить: PR закрыть без слияния, ветку оставить | `gh pr close N` — по слову основателя |
| **закрой PR без состыковки** | Отказ от работы ветки, история сохраняется, в `main` ничего не попадает | `gh pr close N` |
| **слово на один раз** | Одноразовое разрешение (действует только на названное действие) | — |
| **правило** | Постоянное правило, фиксируется в документах дома | коммит + PR |
| **прогон** | Запуск тестов/организма (локально, в CI или на полигоне) | `go test …` / Colab |
| **полигон** | Вне-CI живая среда обкатки (Colab) | `docs/colab-lane.md` |
| **иммунитет** | CI-проверки репозитория | `.github/workflows/ci.yml` |
| **дом** | Репозиторий `COL-O/POTOK` — единственная истина; ветка/gist — рабочие копии | git |

## Как применяется

1. Действие со стороны агента — **только по слову основателя** («слово на один раз» или «правило»).
2. «Состыкуй» ≠ «убери»: слияние никогда не подразумевает удаление ветки; уборка — отдельное слово.
3. Главное слово года: **состыковывай**, не «мержи». Улыбка допускается, подмена смысла — нет.

*Приток, 2026-11-20. По слову основателя; дополнения — PR через круг.*
