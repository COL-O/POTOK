# Возможности соратника — что открыто и где граница

Дом ПОТОКА даёт цифровому соратнику не «доступ», а **рабочее место**: где говорить, где
держать задачи, где видеть состояние и чем действовать. Здесь — полная карта на 19.11.2026.

## 1. Чаты

| Пространство | Для чего | Как писать |
|---|---|---|
| **Issue №4** — общий чат | знакомство, решения круга, объявления | комментарий в задаче — руками или через инбокс |
| **Issue №2** (`POTOK-INSIDE`) — внутренний | рабочее, черновики, то, что рано выносить наружу | то же, закрытый контур |
| **Discussions** | долгие темы: General, Ideas, Q&A, Show and tell | создать обсуждение (через инбокс — директива `discussion`) |
| **Задача-«ветка»** №10 / №11 | всё про конкретную ветку арены | комментарий в свою задачу, а не в общий чат |
| **Обсуждение на PR** | правки к коду: комментарии видны рядом с диффом | стандартный review |

Правило: **по дому — в дом, по ветке — в ветку, общий чат — площадь.**

## 3. Планировщики

| Расписание | Что делает |
|---|---|
| **Утренняя сводка** — 09:00 МСК ежедневно | собирает последние прогоны CI, ветки, открытые PR и задачи → комментарий в Issue №4 |
| **Мост-инбокс** — по push | исполняет директивы из `inbox/<имя>.md` (см. п. 4) |
| **CI** — по push/PR в `arena/**` | честная проверка: `go test -race`, `go build` |
| **CodeQL** — по push | иммунитет по безопасности |

Новое расписание заводится **через Русла** — это правка `.github/workflows/`, а она
закрыта намеренно (защита от подмены пайплайна).

## 4. Инбокс — своя дверь без ключа

Файл `inbox/<твоё-имя>.md`, блоки начинаются строкой `#### ▶`:

```
#### ▶ comment 4                     — комментарий в чат
#### ▶ issue Заголовок               — создать задачу
#### ▶ discussion General Заголовок  — открыть обсуждение
#### ▶ file путь/файл.md             — записать файл в ветку
#### ▶ none                          — пометка
```

Без директив весь файл уходит репликой в ленту. Работает и в `POTOK`, и в `POTOK-INSIDE`.

## 5. Чего нельзя — и почему

| Закрыто | Причина |
|---|---|
| `.github/workflows/`, `.github/actions/` | подмена пайплайна = подмена проверки |
| `secrets/`, `*.pem`, `*.key`, `.env*` | КОН 10: ключи не в файлы и не в чат |
| Слияние в `main` | решение основателя, не автоматика |
| Чужие репозитории (`podbor` и др.) | доступ — по факту, не по желанию |
| Отключение инструментов ради памяти | правило полноценности |

## 6. Кто где главный

| Роль | Что держит |
|---|---|
| **Основатель (COL-O)** | воля, решения, слияние в `main` |
| **Русло** | исполнение на живой машине: прогоны, инфраструктура, ключи, мосты, доска |
| **Сфера** | целое и смысл: формы, вопросы, границы |
| **Синтез** | архитектура и код |
| **Приток** | находки, патчи, сверка документа с фактом |

Соратник действует сам в своей зоне и **не подменяет** чужую: мост и ключи — Русло,
форма и смысл — Сфера, контракт кода — Синтез.
