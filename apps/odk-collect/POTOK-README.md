# ODK Collect — наша копия для правок (ПОТОК)

Эта папка — **снимок открытых исходников ODK Collect**, скопированный
Сферой в репозиторий POTOK 2026-11-18 по слову основателя («куда
сможешь, туда и копируй»: форк от подключения Arena GitHub запретил
403, поэтому копия живёт здесь, где у Сферы есть руки).

- Источник: https://github.com/getodk/collect
- База: релизный тег **v2026.4.0** (не master: авторы сами называют
  master не готовым к производству).
- Лицензия: Apache-2.0 (файл LICENSE.md рядом, сохраняем как есть).
- Размер снимка: 2595 файлов, ~27 МБ, без истории git оригинала.
- Связь с оригиналом: обновления берём сравнением с новым релизным
  тегом вручную; свой форк на странице COL-O остаётся запасным путём
  (создаётся рукой основателя, когда скажет).

## Что нужно для правки кода (честный список)

- **Правки текста** (Kotlin/Java/XML/Gradle): делает Сфера здесь, в
  этой папке — это её руки.
- **Сборка APK**: JDK 17, Android SDK (compileSdk 37, target 36,
  min 26), Gradle подтянет сам wrapper (9.6.1). У Сферы в песочнице
  Java нет — собирает Android Studio основателя/Русла или GitHub
  Actions (отдельным словом основателя о workflow).
- **Отладочная подпись**: в снимке лежит upstream `debug.keystore`
  (публичный отладочный ключ ODK) — только для проб.
- **Релизная подпись**: ключ основателя, на его машине, в репозиторий
  и в чат — никогда.

## Что доделываем под ПОТОК (план, не сделано)

1. Имя и значок приложения ПОТОКА (ресурсы `collect_app/src/main/res`).
2. Сервер по умолчанию — наш Central (self-host), чтобы телефон из
   коробки смотрел домой; QR-настройка App User сохраняется.
3. Русская локаль форм и интерфейса (переводы — открытая часть ODK).
4. Формы — не кодом: XLSForm в Central (см. docs/ODK-ANDROID.md).

Порядок не ломаем: сначала план доделки словом основателя, потом
первая малая правка и пробная сборка APK с фактом (размер, sha256).
