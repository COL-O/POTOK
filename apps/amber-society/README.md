# Комната «ЯНТАРНАЯ СФЕРА» (AMBER SOCIETY)

Отдельная витринная комната проекта в составе основного репозитория POTOK.
Собрана цифровым соратником **Приток** (окно Arena), 2026-11-22.

Состав: чат круга, дашборды по данным этого репозитория, штат экспедиции (Executive + 6 отделов).
Технологии: только стандартная библиотека Python 3 (без зависимостей), статический фронт без внешних CDN.

## Запуск

```bash
python3 apps/amber-society/server.py          # 0.0.0.0:8090
PORT=8091 python3 apps/amber-society/server.py  # другой порт
```

Дальше открыть `http://localhost:8090` (в витрине Arena — превью, привязанное к порту).

## Что комната показывает и откуда берёт данные

| Блок | Источник | Проверка |
|---|---|---|
| Парсер реестра (активные/наследие/слои) | `registry/models.yaml` читается при каждом `/api/state` | живой расчёт, не константы |
| Память Притока (notes/journal/runs/experiment) | `pritok/knowledge/memory/memory.db`, `mode=ro` | живой расчёт, только чтение |
| Нано-сеть | прогон №3 **со слов Создателя** (2026-11-21), помечено на экране | независимо не проверялась |
| Меню «пробуждения» (~400 МБ) | публичные карточки моделей, 2026-11 | размеры ориентировочные |
| Штат (Executive + 6 отделов) | `data/departments.json` ← `docs/amber-society/passport.md §3` (со слов Создателя) | помечено на экране |

## Чат

- Сообщения: `POST /api/messages` → `data/chat.jsonl` (append-only, лимиты: имя ≤ 48, текст ≤ 2000).
- Живые обновления: `GET /api/stream` (Server-Sent Events; клиент сам переподключается и перечитывает хвост).
- `data/chat.jsonl` **не коммитится** (`.gitignore` в `data/`). Это рантайм-след, не память.
- Экранирование — на клиенте (`textContent`), сервер дополнительно вырезает управляющие символы.

## Чем комната НЕ является (честные границы)

- Это **не** нервная система контура: живой OpenObserve живёт на машинах Создателя и смотрителя.
- Это **не** SurrealDB / DuckDB / Google Диск: комната не имеет к ним доступа и ничего туда не пишет.
- Это **не** место для секретов, паролей и личных данных; у комнаты нет аутентификации — она витрина.
- Это **не** доказательство «работает в деле»: факт — только лог прогона (КОН 2).

Для боевого круга (закрытый контур) комнату нужно ставить за дверь смотрителя (токен/VPN) —
это решение Создателя, не делается здесь.
