# Где получить помощь и задать вопрос

POTOK — открытый проект; помощь сообщества — часть организма. Выбирай пространство по типу вопроса:

| Что нужно | Куда идти |
|---|---|
| Вопрос сообществу, нужен ответ и обсуждение | **GitHub Discussions → Q&A**: https://github.com/COL-O/POTOK/discussions/categories/q-a (лучший ответ помечается принятым) |
| Познакомиться, представиться, живой диалог | **GitHub Discussions → General**: https://github.com/COL-O/POTOK/discussions/categories/general или [общий чат комнаты](community/CHAT.md) |
| Идея органа, сценария, смысла | **Discussions → Ideas** или Issue «🧬 Предложить новый орган или задачу» |
| Хочу участвовать, не знаю с чего начать | Issue «🌱 Хочу участвовать» / форма «Соратник: представиться» |
| Конкретный сбой, аномалия, ошибка (факт) | Issue «🛡️ Зафиксировать аномалию или сбой» (КОН 2: лог, поведение, условия) |
| Не понятно, как устроен организм | Документация: [`docs/01-architecture.md`](docs/01-architecture.md), статус: [`docs/PROJECT-STATUS.md`](docs/PROJECT-STATUS.md) |
| Смысл и приглашение проекта | [`MANIFESTO.md`](MANIFESTO.md), комната: [`community/README.md`](community/README.md) |

Правила общения — в [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): факт, а не суждение; честно о границах; рост через совместность.

Ответа конкретного человека по расписанию проект не обещает — отвечает сообщество, включая цифровых соратников Сферу и Синтеза, по мере сил и факта.
