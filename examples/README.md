# EXAMPLES — Примеры запуска и доменного деления организма

В этой директории собраны рабочие сценарии, демонстрирующие эволюцию от минимального спинного мозга до специализированных доменных профилей по закону **КОН 8 (Деление, не строительство)**.

## 1. Карта доступных сценариев

| Профиль | Путь | Задействованные этажи | Дорожки Шины | Что демонстрирует |
|---|---|---|---|---|
| **Simple** (Минимальный старт) | `examples/simple/main.go` | `bus` + `front` (3 органа) | `LanePulse` (0), `LaneHDC` (1) | Базовый такт `Publish -> Step -> Verdict`, штатное узнавание и честный флаг `Surprise` |
| **Drone** (Автономный дрон) | `examples/drone/main.go` | `bus` + `front` (6 органов + 25-й `DroneAcoustic`) | `LanePulse` (0), `LaneHDC` (1), `LaneGraph` (2), `LaneAudio` (8) | Подключение доменного 25-го органа к аудиодорожке и связка с обходом препятствий `D* Lite` и `MCTS` |
| **Full Organism** (Полный цикл) | `cmd/organism/main.go` | Все 4 этажа + HTTP Dashboard | Все 10 дорожек + `SHA-256` WAL на NVMe | Полная спираль жизни: рефлекс → `Surprise` → диагноз → эволюция закона → стресс-тест → реабилитация `VetoMask` → живой дашборд `/metrics` |

## 2. Команды запуска

```bash
# Минимальный рефлекторный контур
go run ./examples/simple/main.go

# Профиль автономного дрона
go run ./examples/drone/main.go

# Полный 4-этажный живой организм с HTTP-дашбордом
go run ./cmd/organism/...
```

## 3. Как добавить свой профиль (например, `examples/transport/`)

1. Выберите нужные дорожки Шины (`LaneGraph` для маршрутов, `LaneTensor` для потоков датчиков, `LaneVector` для семантики).
2. При необходимости добавьте специализированный орган в слоты `24..31` по инструкции из `docs/11-contributing.md`.
3. Соберите `OrganRegistry` только из тех органов, которые нужны вашей задаче — остальные останутся спящими и не займут ни одного байта в горячем кэше CPU.
